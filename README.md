# Minimal Mirror

![The idea of out Minimal Mirror](/assets/MinimalMirror.jpeg)

## The Baseline

The idea is to build an open source modular smart mirror powered by Raspberry Pi 3 Model B+.

## Further developments and ideas

For a successful design, development , implementation and a right assembly of the smart mirror, we decided to divide the project in two main tasks:

1. 💻 **Software:** Implementation of modules to make the mirror more interactive ([Available modules](https://github.com/MichMich/MagicMirror/wiki/3rd-party-modules)).
2. 🔧 **Hardware:** Purchase and assembly of components.

### Software 💻

For the software side, we rely on the MagicMirror² project: an open source modular mirroring platform to which we have implemented some modules:

- Calendar
- NewsFeed
- OClock
- OpenmapWeather
- NowPlayingOnSpotify
- QRCode
- TelegramBot
